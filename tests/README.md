# Behavioral Tests

These are manual scenario tests, not automated tests. They do not promise identical results across models or platforms.

## How to use
1. Start a fresh conversation with the Skill enabled.
2. Try a prompt from `test-cases.md`.
3. Review the behavior against the expected signals.
4. Record the model, host platform, observed behavior, and any failure.
5. Revise instructions when a repeatable issue or meaningful gap is found.

Evaluate the interaction pattern, not just the final artifact.
