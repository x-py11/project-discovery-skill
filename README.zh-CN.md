# Project Discovery & Delivery｜项目需求探索与交付

**一个通用型 Agent Skill：帮助 AI 澄清项目目标、动态追问、整理项目简报，并判断何时应该继续提问、制定计划或开始执行。**

[English README](README.md)

## 为什么需要它？
很多项目一开始只有一个想法，还没有完整需求。太早开工可能导致返工；问题问得太多，又会让沟通像填表一样繁琐。

这个 Skill 希望取得平衡：**只问那些真正有助于理解方向的问题，确认方向后就及时推进。** 它希望 AI 像一个会倾听、有判断力的合作伙伴，而不是机械执行的工具，也不是不沟通就擅自决定一切的助手。

## 主要能力
- 了解目标、受众、交付物、约束和成功标准。
- 根据尚未明确的内容，动态提出少量高价值问题。
- 用户不确定时，主动给出推荐方案和合理默认值。
- 尊重“你来决定”“别再问了，直接做”等授权。
- 区分已确认决定、AI 做出的假设和仍待解决的问题。
- 为多阶段项目维护简洁的项目简报。
- 判断何时停止追问、开始执行。
- 适用于 PPT、网站、软件、海报、报告、视频、思维导图、数据分析等项目。

## 核心原则
> Project Discovery 的目标不是尽可能多地提问，而是在执行前尽可能减少本可避免的误解。

## 如何使用
本项目采用常见的 Agent Skill 组织方式，将主要指令放在 `SKILL.md`，并通过 `references/` 提供补充规则。不同 Agent 平台的安装目录和技能发现机制可能不同，请查看[安装指南](docs/installation.md)和[兼容性说明](docs/compatibility.md)。

## 测试与贡献
`tests/test-cases.md` 提供可手动检查的行为测试场景。这些不是自动化基准，实际表现会受到模型和宿主平台影响。欢迎提交问题和改进建议，详见 [`CONTRIBUTING.md`](CONTRIBUTING.md)。
