# Contributing

Thanks for helping improve Project Discovery & Delivery.

## Useful contributions
- Report repeatable cases where the Skill asks too many or too few questions.
- Suggest clearer wording or better defaults.
- Add project-type examples that generalize beyond one user.
- Improve the brief template, compatibility notes, or test scenarios.
- Report ambiguous or contradictory instructions.

## Before opening an issue
When possible, include the host platform and model, a minimal reproducible prompt or conversation, expected behavior, observed behavior, and why the difference matters. Remove personal, confidential, or sensitive information.

## Pull requests
- Keep changes focused and explain the problem they solve.
- Update docs or test scenarios when behavior changes.
- Prefer reusable principles over rules tailored to one example.
- Do not claim universal platform compatibility without evidence.
- Preserve the core principle: minimize avoidable misunderstanding without unnecessary conversational friction.

Issues and contributions in English or Simplified Chinese are welcome.
