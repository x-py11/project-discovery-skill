# Installation Guide

This repository provides Skill instructions and supporting reference files. Installation varies by host platform.

1. Download or clone this repository.
2. Place the `project-discovery-skill` directory in the skill directory recognized by your agent platform.
3. Keep `SKILL.md` at the root and preserve the `references/` directory.
4. Follow the host platform's instructions for importing, enabling, or discovering skills.
5. Test with both a vague request and a clear request.

There is no single universal installation path or activation command across all agent products. Check the documentation for your specific host.
